# MakeHuman data (CC0)

`makehuman_cc0.npz` and `mh_skin_young_male.png` are extracted from MakeHuman's system assets by
`../mh_extract.py`:

- the base mesh (`base.obj`: body, helper eyeballs, joint markers, UVs),
- the targets the character generator uses (the macro body targets for a young adult male plus a few
  measure / muscle / face targets),
- one system skin texture (young light-skinned male).

**License:** MakeHuman's base mesh, targets, proxies and system skins are graphical assets released under
**CC0 1.0** (public domain dedication). Since the 2020 license clarification, the project states that these
assets are CC0 no matter how they were obtained, and that models made with them can be used in closed-source
and commercial games without attribution:

- https://static.makehumancommunity.org/oldsite/faq/what_changed_regarding_the_license_in_2020.html
- https://static.makehumancommunity.org/makehuman/faq/are_makehuman_files_free.html

Some third-party clothes and hair proxies in MakeHuman's community library carry other licenses (CC-BY); none of
those are used here. All clothing and gear of the VEXA characters is generated by `vexa_outfit.py`.

The data was taken from the npm package `makehuman-data` (a JSON/binary conversion of the MakeHuman 1.1 data).
That package's own metadata still lists the pre-2020 AGPL notice of the MakeHuman assets; the CC0 dedication
above supersedes it for the asset files themselves.
